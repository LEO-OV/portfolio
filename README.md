# Portafolio Leonardo Velasco

Sitio web personal de Leonardo Velasco, enfocado en presentar perfil profesional, habilidades, educacion, certificaciones, proyectos y medios de contacto.

El proyecto esta construido como un sitio estatico con HTML, CSS y JavaScript vanilla. Incluye soporte bilingue espanol/ingles, cambio de tema claro/oscuro, renderizado dinamico de proyectos y enlaces al CV segun el idioma seleccionado.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- JSON para contenido multilenguaje
- SVG y WebP para recursos visuales

## Estructura del proyecto

```text
.
+-- index.html
+-- assets
    +-- docs
    |   +-- CV_Leonardo_Velasco.pdf
    |   +-- CV_Leonardo_Velasco_eng.pdf
    +-- fonts
    +-- icons
    +-- images
    |   +-- projects
    +-- js
    |   +-- main.js
    +-- lang
    |   +-- en.json
    |   +-- es.json
    +-- styles
        +-- normalize.css
        +-- styles.css
```

## Secciones principales

- Hero con nombre, descripcion, botones de proyectos, CV y redes.
- Sobre mi con perfil profesional, habilidades, educacion y certificaciones.
- Proyectos con tarjetas generadas dinamicamente.
- Contacto con enlaces directos.
